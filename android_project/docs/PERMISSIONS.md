# Permissões e Conformidade

- `BIND_ACCESSIBILITY_SERVICE`: Utilizado unicamente para ler dados numéricos e textos da oferta na tela do motorista.
- `SYSTEM_ALERT_WINDOW`: Utilizado para exibir a overlay flutuante por cima do app oficial de navegação/motorista.
- `POST_NOTIFICATIONS`: Notificação permanente do Foreground Service de turno ativo.
- `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`: Garante que o Android não encerre o cálculo durante a corrida.
